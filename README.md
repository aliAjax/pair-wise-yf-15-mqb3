# hxyfront-62003 法医昆虫学跨案联检台

源提示词编号：5

在样本记录页基础上补成的跨案联检台：预置三案六样，鉴定员勾选至少两份样本建立联检批。

## 联检规则

- 虫种相同、发育阶段相同；
- 批内采样时刻相距不超过 24 小时；
- 保存方式一致；
- 案件已封存、已进别批的样本退回并展示理由；
- 联检编号（如 `LJ-2026-001`）同步到名册、温度曲线、案件关联页与详情卡片。

## 模块划分（无新增依赖、无后端）

| 模块 | 位置 | 职责 |
| --- | --- | --- |
| 判定 | `src/domain/` | 入批判定纯函数：逐份样本给出入批 / 退回理由 |
| 资料存取 | `src/data/` | 冻结的预置名单 + 不可变工作台状态与只读选择器，成批不改写原名单与旧批 |
| 页面交互 | `src/ui/` + `src/App.tsx` | 名册勾选、阶段筛选、温度曲线、批次列表、案件关联页、详情卡片 |

## 技术栈

React + Vite + TypeScript

```bash
npm install
npm run dev
```
